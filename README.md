# 🤖 My AI Chatbot

A personal AI chatbot built using JavaScript, Node.js, Express.js, and the Gemini API.

## ✨ Features

- 💬 AI-powered conversations
- 🖼️ Image analysis
- 📄 PDF file support
- 📁 File attachments
- 💾 Chat history using browser local storage
- 🆕 Create new conversations
- 🗑️ Clear chat
- ✍️ Markdown-formatted AI responses
- ⏳ AI response loading indicator
- 📱 Responsive and interactive user interface
- ⚙️ Custom AI instructions
- 🔐 API key stored securely using environment variables

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- Google Gemini API
- LocalStorage
- Git & GitHub
